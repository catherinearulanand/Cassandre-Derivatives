Cassandre control — federation layer

Validates and correlates signed envelopes from ClauseOS / RiskOS / CollateralOS. Imports nothing from those products (plan Section 3.4, AET-006). Synthetic SIM-* data only.

Envelope submission

Paste or upload a signed cassandre_contracts.Envelope JSON document. On rejection, every exact failure reason from verify_envelope's closed set is shown (e.g. CONTENT_HASH_MISMATCH, UNKNOWN_OR_REVOKED_KEY_ID, SIGNATURE_INVALID, MISSING_SIGNATURE, AUDIENCE_MISMATCH, PURPOSE_NOT_PERMITTED, STALE, AUTHORITY_STATUS_NOT_PERMITTED) — never collapsed to a generic "error".

Correlated case view

Look up a case by its correlation key (each envelope's simulation_provenance.scenario_id). Shows which of ClauseOS / RiskOS / CollateralOS have submitted an accepted envelope for that case, and whether it is cross-product complete (all three present).

Federated audit export

Assembles a read-only bundle from already-verified envelope receipts for one correlation key (plan Section 3.4: "assemble a federated audit bundle"). Rendered as a table by default; toggle raw JSON below.
