Eligibility matrix and rule evidence

There is no standalone eligibility-preview endpoint in this slice. This matrix is derived from GET /v1/plans/{plan_id}/evidence's verifier_notes, which record every position the independent verifier rejected and its full ordered reason list — never a bare boolean (plan Section 12.3). Run a plan first (Planner results tab), then look it up here.

Rejected assets and infeasibility diagnosis

Same evidence source as the eligibility matrix: verifier_notes from GET /v1/plans/{plan_id}/evidence. This view instead groups by violation category (ineligible position, exceeds available inventory, minimum-lot violation, concentration cap, insufficient coverage, solver-level infeasibility) so an infeasible plan's root cause is legible at a glance.

Counterfactual analysis and audit export

Not yet implemented.
